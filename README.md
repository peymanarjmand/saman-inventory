# Saman Inventory Poster Generator

یک صفحه‌ی HTML/CSS/JS ساده برای ساخت عکس لیست موجودی بازی‌ها.

## امکانات

- ورود عنوان کانال و زیرعنوان
- ورود تاریخ شمسی با سه فیلد سال، ماه و روز
- ورود لیست بازی‌ها به صورت خط به خط
- امکان کم و زیاد کردن لیست فقط با ویرایش متن
- امکان تغییر لوگو از داخل صفحه
- ساخت خروجی PNG با ابعاد 864×1536
- قابل دیپلوی روی GitHub Pages بدون بک‌اند و بدون دیتابیس

## اجرای لوکال

فایل `index.html` را مستقیم در مرورگر باز کنید.

## دیپلوی رایگان روی GitHub Pages

1. یک ریپازیتوری جدید در GitHub بسازید.
2. فایل‌های این پوشه را داخل ریپازیتوری آپلود کنید.
3. از مسیر Settings → Pages، بخش Branch را روی `main` و مسیر را روی `/root` بگذارید.
4. چند دقیقه بعد لینک GitHub Pages ساخته می‌شود و کارفرما می‌تواند از همان لینک استفاده کند.

## تغییر لوگوی پیش‌فرض

فایل زیر را جایگزین کنید:

`assets/logo.jpeg`

یا از دکمه‌ی «تغییر لوگو» داخل خود صفحه استفاده کنید.
